# Retail Online Store A polished retail storefront built with Python and Flask. The project includes a professional homepage, searchable product catalog, product categories, shopping cart, account registration/login, and a demo checkout flow. No real payment processing is connected. ## Features - Professional storefront landing page - Searchable catalog and category filtering - Shopping cart with quantity updates and total pricing - User registration and login with secure password hashing - Demo checkout that records an order without processing payment - Responsive design for desktop and mobile - Legacy demo preserved at `/legacy` ## Tech stack - Python 3 - Flask - SQLite - HTML - CSS - JavaScript ## Run locally ```bash python -m venv .venv source .venv/bin/activate pip install -r requirements.txt python app.py ``` Then open: ```text http://127.0.0.1:5000 ``` ## Routes - `/` — main storefront homepage - `/catalog` — catalog with search and category filtering - `/cart` — cart summary and quantity edits - `/login` — user login - `/register` — user registration - `/checkout` — demo checkout flow - `/legacy` — original static demo page ## Notes - User data and demo order records are stored in `store.db`. - The project is intentionally a demo storefront and does not connect to a payment provider. - The `main` branch remains untouched; feature work is kept on `feature/storefront-mvp`. ## Developer Anmol Preet Singh
