# Retail Online Store A polished retail storefront built with Python and Flask. The project includes a professional homepage, searchable product catalog, shopping cart, user login and registration, and a demo checkout flow. It intentionally does not process real payments. ## Features - Professional storefront landing page - Searchable product catalog - Shopping cart with quantity updates and total pricing - User registration and login using secure password hashing - Demo checkout with order persistence in SQLite - Fully responsive design for mobile and desktop ## Tech stack - Python 3 - Flask - SQLite - HTML, CSS, and JavaScript ## Run locally ```bash python -m venv .venv source .venv/bin/activate pip install -r requirements.txt python app.py ``` Then open: ```text http://127.0.0.1:5000 ``` ## Notes - The app stores demo order data in `store.db`. - The legacy single-page demo remains available at `/legacy`. - No real payment provider is connected. ## Developer Anmol Preet Singh
